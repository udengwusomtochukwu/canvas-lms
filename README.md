Canvas LMS
======

> **Page Schools fork — Manual Exam Workflow.** This fork adds a native,
> feature-flagged workflow for on-paper exams: teachers upload scanned,
> hand-graded scripts, enter scores through the standard grading path, and
> fill the aligned rubric so outcome mastery reflects the exam. Enable via
> **Account > Settings > Feature Options > "Manual Exam Workflow"**
> (`manual_exam_workflow`, account-level, default off; when off behaviour is
> exactly stock Canvas). Optional related flags: outcome mastery scales
> (`account_level_mastery_scales`) for mastery display; no file-access
> settings changes are required. See `doc/manual_exam_workflow.md`,
> `DISCOVERY.md` and `FORK_CHANGES.md`.

Canvas is a modern, open-source [LMS](https://en.wikipedia.org/wiki/Learning_management_system)
developed and maintained by [Instructure Inc.](https://www.instructure.com/) It is released under the
AGPLv3 license for use by anyone interested in learning more about or using
learning management systems.

[Please see our main wiki page for more information](http://github.com/instructure/canvas-lms/wiki)
